# English Buddy Bot

Telegram-бот для изучения английского. Проверяет грамматику в реальном времени, объясняет ошибки, помогает с переводами и произношением.

Работает в двух режимах:
- **Обычный бот** — команды и кнопки в личке бота
- **Business Mode** — подключается к Telegram Business и проверяет сообщения прямо в переписках с другими людьми

## Возможности

| Функция | Описание |
|---------|----------|
| **Авто-проверка** | В Business Mode проверяет каждое сообщение. Сначала бесплатно через LanguageTool API, если есть ошибки — GPT делает подробный разбор |
| **Ручная проверка** | Ответь `?` на своё сообщение — бот удалит `?`, проверит грамматику + естественность, исправит оригинал и пришлёт разбор в ЛС |
| **AI Чат** | Свободный чат про английский. Грамматика, правила, разница между словами |
| **Как сказать** | Фраза на русском → варианты на английском (casual, formal, slang) |
| **Слово** | Перевод, синонимы, примеры, коллокации |
| **Что имел ввиду** | Объяснение фраз, сленга, идиом |
| **Диалоги** | Ролевые диалоги (собеседование, ресторан, аэропорт и др.) с оценкой |
| **Голосовое** | Анализ произношения, оценка американского акцента |
| **Тренировки** | Упражнения на основе твоих ошибок |
| **Тест уровня** | A1–C2 |
| **Словарь** | Сохранение слов + повторение по системе Лейтнера |
| **Прогресс** | Статистика, стрики, XP, уровни |

## Как работает проверка в Business Mode

```
Сообщение в любом чате
  ↓
Фильтры (мгновенно, бесплатно):
  короткое? не английское? "ok/thanks/lol"? → скип
  ↓
LanguageTool API (бесплатно, ~0.5 сек):
  нет ошибок → скип, +XP
  есть ошибки ↓
  ↓
GPT-4o-mini (~0.001$, ~3-5 сек):
  → исправляет оригинал прямо в чате
  → отправляет подробный разбор в ЛС бота
```

Ручная проверка:
```
Ответь "?" на своё сообщение
  ↓
Бот удаляет "?" → GPT проверяет грамматику + естественность
  → исправляет оригинал → разбор в ЛС
```

~90% сообщений фильтруются бесплатно. GPT вызывается только когда реально есть ошибки.

## Требования

- **Python 3.9+**
- **Telegram Bot Token** — [@BotFather](https://t.me/BotFather)
- **OpenAI-совместимый API ключ** — для GPT и Whisper

### API провайдер

Бот использует OpenAI-совместимый API. Подойдёт любой провайдер — достаточно поменять `OPENAI_BASE_URL` и модель в `bot/config.py`:

```python
# ProxyAPI (по умолчанию)
OPENAI_BASE_URL = "https://api.proxyapi.ru/openai/v1"
OPENAI_MODEL = "gpt-4o-mini"

# OpenAI напрямую
OPENAI_BASE_URL = "https://api.openai.com/v1"
OPENAI_MODEL = "gpt-4o-mini"

# Любой совместимый провайдер
OPENAI_BASE_URL = "https://your-provider.com/v1"
OPENAI_MODEL = "your-model"
```

## Настройка Telegram Business

1. Создай бота через [@BotFather](https://t.me/BotFather)
2. В Telegram: **Настройки → Telegram Business → Чат-боты** → подключи бота
3. Бот начнёт проверять твои сообщения в переписках

### Проверка через "?"

В любом бизнес-чате ответь `?` на своё сообщение. Бот:
1. Удалит `?`
2. Проверит грамматику и естественность
3. Если есть ошибки — исправит оригинальное сообщение
4. Пришлёт подробный разбор в личку бота

## Стоимость

| Действие | Стоимость |
|----------|-----------|
| Фильтры + LanguageTool | Бесплатно |
| Сообщение с ошибкой (GPT) | ~$0.001 |
| Голосовое (Whisper + GPT) | ~$0.005 |
| **100 сообщений/день** | **~$0.50–1.00/мес** |

LanguageTool API фильтрует ~60–80% сообщений бесплатно. GPT вызывается только при реальных ошибках.

## Конфиденциальность

- **LanguageTool API** — тексты отправляются на `api.languagetool.org` для проверки. [Не хранят тексты](https://languagetool.org/privacy/)
- **OpenAI API** — тексты обрабатываются через выбранного провайдера. При использовании API [данные не используются для обучения](https://openai.com/enterprise-privacy/)
- **БД** — хранится локально (SQLite). Ошибки, статистика, словарь — всё на твоём сервере
- Бот видит только сообщения из бизнес-чатов, ничего не пересылает третьим лицам

## Известные ограничения

- **Реакции в Business Mode** — Telegram Bot API не поддерживает `message_reaction` в бизнес-чатах. Используй `?` как альтернативу
- **LanguageTool API** — бесплатный публичный API, лимит 20 запросов/минуту. Для личного использования хватает. При ошибке API — сообщение автоматически отправляется на GPT
- **Короткие фразы** — LanguageTool плохо ловит ошибки в коротких фразах (2-3 слова). Используй `?` для ручной проверки
- **SQLite** — для одного пользователя. Для нескольких — лучше PostgreSQL
- **Промпты на русском** — бот заточен под русскоязычных пользователей
